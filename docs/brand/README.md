# Pairbar identity

Pairbar = two accounts paired in the macOS menu bar. The repository is `isaacstg/pairbar`. Its former `codex-dual-account-switcher` URL redirects; the description and README retain ChatGPT/Codex account-switcher keywords for discoverability.

- **Tagline:** Two accounts. One click apart.
- **Palette:** ink `#0B1220`, mint `#69DCC8`, amber `#F6BC73`, paper `#F4F7FB`.
- **Mark:** two parallel rounded bars with a small connecting segment; one account stays ordinary while the other is added alongside it.
- **Assets:** `logo.svg` and `banner.svg` are editable, first-party static vectors. `social-preview.png` is a 1280×640 export for GitHub's social preview setting and link cards.

The banner's small app panel is an interface illustration based on 1.3, not a screenshot. It contains synthetic Personal/Work labels, no real account identity or diagnostic output, and no OpenAI logo.

The brand currently applies to the public project page. The installed 1.3 app keeps its existing display name, bundle identifier, package executable, data root, and archive filename. A future app branding release must preserve upgrade compatibility.

All assets use the repository's MIT license. Social-preview upload is a separate repository UI setting; adding the PNG to Git does not automatically configure that setting.
